## 2024-06-22 - Form Input Accessibility
**Learning:** Adding `htmlFor` on a `<label>` and the matching `id` on the input makes inputs readable for screen readers and clickable via the label. Required fields should also be semantically marked with the `required` attribute and visually marked with a red asterisk using Tailwind (`<span className="text-red-500">*</span>`).
**Action:** Always verify label-input association and explicit required states in future form changes.
